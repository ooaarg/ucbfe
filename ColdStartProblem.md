# Some topics about the Cold Start Problem

- https://arxiv.org/pdf/2308.08354 Is Meta-Learning the Right Approach for the Cold-Start Problem in Recommender Systems?
This article has cold start metrics: NDCG@5, ROC AUC
- https://www.mdpi.com/2078-2489/14/1/19 - paper for dataset https://github.com/lynchblue/movie-rating-dataset CSP Dataset (Cold-Start Problem)
They report that their dataset is specified in particular fot the cold start problem
- https://repository.upenn.edu/server/api/core/bitstreams/ac3a57bf-b455-4a21-b2d0-d11321093ea5/content#page=4.91 Methods and Metrics for Cold-Start Recommendations
The classic paper from 2002 with 2674 citations - the main idea - to use metric ROC AUC
- https://github.com/KevKibe/Solving-the-cold-start-problem - small git for classic solution for cold start problem
